Task 5 — Product Sales Analysis (Internship Project)

Overview
This repository contains SQL queries for **Task 5** of my internship program, focused on analyzing product sales data using the **Chinook MySQL database**.  
The goal was to extract business insights such as top-selling products, revenue per region, monthly performance, and customer-specific trends.

Dataset
- Database-Chinook MySQL
- Description- A sample digital media store database containing:
  -> Customers
  -> Invoices & Invoice Lines
  -> Tracks, Albums, Artists, and Genres
- Source- [Chinook Database GitHub](https://github.com/lerocha/chinook-database)
